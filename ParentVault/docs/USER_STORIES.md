# ParentVault User Stories

## Parent onboarding and trust

- As a parent, I want to understand what data ParentVault stores before I create a vault, so I can decide whether to trust it.
- As a parent, I want to lock the app with biometrics or PIN, so someone with my phone cannot open sensitive child records.
- As a parent, I want export and delete options, so I am not trapped in the product.

## Child profiles

- As a parent, I want to create a profile for each child, so I can keep key details together.
- As a parent, I want SSN and medical fields masked by default, so sensitive information is not exposed casually.
- As a parent, I want to store emergency contacts, allergies, medications, and notes, so I can find them quickly in stressful moments.

## Schedules and reminders

- As a parent, I want to create custody, school, event, and medication schedule items, so I can see what is coming up.
- As a parent, I want day-before, day-of, hour-before, and custom notifications, so reminders match the way my life actually runs.
- As a parent, I want to mark a medication as taken, so I can avoid double doses or forgotten doses.
- As a parent, I want a today/next-up view, so the app immediately answers “what do I need to do now?”

## AI import and chat

- As a parent, I want to upload a flyer, screenshot, PDF, calendar, or decree, so ParentVault can help extract dates and tasks.
- As a parent, I want to review proposed changes before saving, so AI mistakes do not corrupt my records.
- As a parent, I want warnings and confidence indicators, so I know what needs manual checking.
- As a parent, I want to type or dictate “add soccer every Tuesday at 6,” so common updates are fast.

## Journaling

- As a parent, I want to make factual journal entries with dates, notes, tags, and attachments, so I can keep a reliable history.
- As a parent, I want to mark attachments as redacted, so I can track privacy-sensitive files.
- As a parent, I want journal export later, so my notes remain useful outside the app.

## Cloud-first and self-host future

- As a parent, I want the cloud version to just work on Android and iOS, so I do not need to run a server on day one.
- As a privacy-focused parent, I want a later self-host option, so I can move records to hardware I control.
- As a parent, I want migration between cloud and self-host to be understandable, so I can choose the right privacy/convenience tradeoff.

## Admin/support stories

- As support, I need audit metadata without sensitive payloads, so I can troubleshoot safely.
- As an operator, I need import job failures to be visible without exposing private documents, so reliability can improve.
- As an operator, I need a clear incident response process, so families can be notified quickly if something goes wrong.
