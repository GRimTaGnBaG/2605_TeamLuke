# ParentVault MVP

## Target user

A parent who needs a secure, practical way to manage child-critical information, custody/school schedules, medication reminders, and incident journaling without digging through scattered texts, PDFs, flyers, and calendars.

## MVP promise

ParentVault gives parents one private place to keep child details, turn messy inputs into reviewable schedule items, get reminders, confirm meds, and preserve important events with evidence.

## Core flows

1. Create child profile with birthdate, allergies, medications, emergency contacts, and encrypted identity fields.
2. Add schedule items manually or by chat.
3. Import image/PDF/calendar/flyer/decree and review AI suggestions.
4. Receive custom notifications: day before, day of, hour before, and custom offsets.
5. Mark medication reminders as taken.
6. Journal event notes with photos/screenshots.
7. Switch backend mode later from cloud to self-hosted server.

## Out of scope for first build

- Legal advice or custody recommendation.
- Automatic unreviewed modification of schedules from decrees or AI.
- Sharing records with courts, doctors, or co-parents before permission model is designed.
- Full E2EE implementation until key management is finalized.

## Launch checklist

- [ ] Biometric/PIN app lock.
- [ ] Encrypted storage for SSN/medical data.
- [ ] Account auth and recovery design.
- [ ] AI import review/diff UI.
- [ ] Notification reliability testing on iOS and Android.
- [ ] Data export/delete.
- [ ] Privacy policy and security review.
- [ ] Self-host pairing proof-of-concept.
